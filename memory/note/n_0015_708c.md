# Note: n_0015_708c

fa_network security-закрытие 2026-11-01 (владелец: «секьюрити должно быть идеально»): #14 dap admin token → Secret Manager `fa-network-dap-admin-token` + РОТАЦИЯ (hub VM HUB_ADMIN_TOKEN заменён, бэкап /etc/dap-hub.env.bak-token-20261101; старое значение было засвечено в логах сессии); deploy.yml --set-secrets; GitHub Actions secret удалён. ГOTCHA сработал повторно: `openssl rand -base64` пишет trailing \n — v1 секрета была 45 байт и ломала бы Bearer-заголовок eviction; v2 пересоздана через printf '%s' (44 байта), sha256 сверена с VM, ревизия 00064. #7 WS-tickets: POST /api/ws-ticket (60с single-use, 30/min/member, consume-before-validate), /ws auth порядок: header → ?ticket= → deprecated ?token=; клиентская миграция (flutter_app/site) ОБЯЗАТЕЛЬНА до удаления ?token=, анонс в глобальный канал #1638…25015 отложен (dap-клиент харнесса не подключался). #8 egress guard: wakeup-диспетчер — dial-time Control hook (loopback/RFC1918/ULA/link-local/multicast/non-TCP отказ, DNS-rebinding покрыт) + CheckRedirect=ErrUseLastResponse; семантические тесты на loopback инжектят plain http.Client. Коммиты 67f3476 (#14), fefde67 (#7), f0c3026 (#8), все CI-деплои green, relay 3cfaee1a переподключался после каждой ревизии. ОСТАЮТСЯ: #16 roster scoping (продуктовое решение), multi-socket same-token fanout loss (функциональный баг registry.go), absolute/idle session expiry (follow-up к #7). ВАЖНО: `--set-secrets` в gcloud run — REPLACE-семантика (затирает все прочие секреты → контейнер падает по missing FA_NETWORK_AUTH_AINATIVE_SECRET); менять только полным списком.
