# Note: n_0017_d37a

fa_network cost/perf 2026-11-04 (владелец): deploy --min-instances 0 (было 1) — по директиве владельца, следствие: idle scale-to-zero убивает dap-relay и WS, первый запрос платит cold start. Замер CPU по Monitoring API: fa-network реально 0.3–1.3% (mean) за 6ч, все Cloud Run сервиса проекта холодные, VM: dap-hub-vm 2%, wg-vpn-1 52% (NAT) — цифра «216%» не соответствует ни одному живому ресурсу, источник не найден. Оптимизации сделаны всё равно: (1) Relay.ownedAgentNames кэш TTL 15s + InvalidateOwned на enroll/drop (иначе #16-фильтр бил в стор на каждый presence-flap × сеть), тест TestOwnedAgentNamesCache; (2) Server.touchSession троттлинг 1/min на сессию (было 2 PG-записи на каждый authed-запрос), тест TestTouchSessionThrottle; тесты используют env.enrollAgent helper (claim+invalidate).
