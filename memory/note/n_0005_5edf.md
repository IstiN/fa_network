# Note: n_0005_5edf

fa_network 2026-09-27: «невидимка» инцидент закрыт. Root cause #2 (после ephemeral identity): релей join'ил каналы хаба ТОЛЬКО лениво при исходящем send, и d.joined переживал реконнекты → после рестарта релей был глух к inbound. Фикс в main: join ledger сбрасывается per-connection + Relay на EventOnline джоинит ВСЕ каналы из стора (hub.Client.Join). Секрет fa-network-dap-identity-seed был битый с самого создания (префикс "-n " от echo) — seed молча не работал; починен версией 2, теперь hub identity релея стабильна: 3cfaee1aa054fe6e (a3c9615a… была ephemeral). Конфиг прода: min=max=1 инстанс; после каждого CI-деплоя перевыполнять gcloud run services update (min/max + --update-secrets FA_NETWORK_DAP_IDENTITY_SEED), пока не запушен коммит 8847132 с патчем deploy.yml (ждёт workflow-scope: owner должен сделать `gh auth refresh -h github.com -s workflow`). Локальный доступ к БД: authorized networks на learn-ai-db был пуст — добавлен 37.212.88.56 (мой IP на тот момент); psql/pg-драйверов на машине нет — работает go run с pgx из модуля репо (скрипт /tmp/dbq).
