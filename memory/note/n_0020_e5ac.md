# Note: n_0020_e5ac

fa_network: POST /api/devices/enroll 500 root cause (fixed 5950127): персональная сеть без пароля → CreateNetwork биндил nil []byte как SQL NULL против NOT NULL password_hash → SQLSTATE 23502 на КАЖДЫЙ первый enroll; mem-store SQL-констрейнты не представляет (memory-only контракт-лега слепа к таким багам). Фикс: nonNilBytes (пустая bytea) в CreateNetwork/UpdateNetwork, writeStoreErr теперь логает underlying err, opt-in PG контракт-лега FA_NETWORK_TEST_PG_URL (TRUNCATE на каждый сабтест), PG CreateChannel назначает id при пустом (паритет с mem/chanID). Урок: любые NOT NULL/UNIQUE-зависимые пути требуют PG-леги, mem-тесты их не покрывают.
