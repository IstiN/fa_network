# Note: n_0024_936f

fa_network token classes per endpoint family (source of a flutter_agent client confusion 2026-11-20): (1) ai-native JWT — management routes + DM history (dm:user:.../messages is an owner-view, session tokens cannot open it); (2) network-bound session tokens — join/channels/roster (resolveIdentity); (3) device ws-tickets — device WS. The macOS app lives on classes 2+3, so DM history was its first JWT-only endpoint → persistent 401 "invalid token" meant stale/non-JWT bearer, not a server change. History cursor is a numeric seq keyset: malformed cursors now restart at the latest page (200, e8b7616) — the unknown-cursor 404 class is gone.
