# Note: n_0004_d28f

fa_network ai-native auth REAL contract (verified live 2026-09-25): ai-native.cloud is an IstiN/auth deploy in project dmtools-oauth-1749672403. Tokens are HS256 with the shared JWT_SECRET (SM auth-jwt-secret there; copied to ai-native-478811 as fa-network-ai-native-secret → env FA_NETWORK_AUTH_AINATIVE_SECRET). Claims: iss=ai-native.cloud, sub=email, userId, role, products. NO JWKS/RS256 — an earlier RS256-discovery provider was broken against prod and has been rewritten. fa_network fetches the locked display name from GET /api/auth/user (Bearer), 5-min cache, email fallback. Native client flow: GET /api/oauth-proxy/providers → POST /api/oauth-proxy/initiate {provider, client_redirect_uri, client_type, environment} → {auth_url,state,expires_in} → browser → client_redirect_uri?code&state → POST /api/oauth-proxy/exchange {code,state} → {accessToken,refreshToken,expiresIn,...}. Loopback redirect URIs always allowed; custom schemes (fa://) need OAUTH_ALLOWED_REDIRECT_URIS in the auth deploy (learn.ai submodule — owner action).
