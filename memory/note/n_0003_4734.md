# Note: n_0003_4734

dap hub production: Cloud Run service dap-hub in ai-native-478811/us-central1, custom domain https://hub.fa1.dev (managed cert), /data on GCS fuse bucket dap-hub-data, secrets dap-hub-master-secret + dap-hub-admin-token (create with printf '%s' — trailing newline breaks both the hub startup auth and WS Authorization headers; secret env vars need a new revision to refresh). Deploy workflow lives in the dap repo (.github/workflows/deploy-cloudrun.yml) but GitHub WIF from that repo fails getAccessToken on ANY service account (unresolved; hub was deployed manually from the owner's machine). fa_network talks to it as agent fa-network-relay via FA_NETWORK_DAP_URL=wss://hub.fa1.dev/ws + FA_NETWORK_DAP_SECRET (wired in deploy.yml --set-secrets). TRANSCRIPT REDACTOR GOTCHA: typing secret-looking key=value patterns (e.g. *_SECRET=...:latest, HUB_ADMIN_TOKEN) in bash commands/heredocs gets replaced with literal [REDACTED:...] text before execution — build such strings via concatenation and verify with od.
